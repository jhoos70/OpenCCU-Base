## Format

`- [ ] T### [P?] [US#|ICxxx|CFxxx] [GATED:EG-n]? Description with backtick path`

Path conventions (all under the OWNING component output_dir `<dir>`):
- Test: `<dir>/tests/<spNNN>.test` (one tcltest file per SP, e.g. `sp001.test`)
- Source: `<dir>/<repo-layout path>` mirroring the repo below the API tree, e.g. `<dispatcher_dir>/homematic.cgi`, `<security-session_dir>/eq3/session.tcl`, `<system-admin_dir>/methods/ccu/createfile.tcl`
- Integration / NFR coverage: `<dir>/tests/integration/<slug>.test`
- Flow: `<dir>/tests/flows/<cfNNN>.test`
- Runner: `<dir>/tests/all.tcl` (sources every `*.test` under `tests/`, `tests/integration/`, `tests/flows/` via `tcltest::runAllTests`)
- Mock reuse: only `schema-harness` writes mock helpers (`tests/helpers/*.tcl`). Other components load them read-only with `source [file normalize [file join [file dirname [info script]] .. .. schema-harness tests helpers mocks.tcl]]` (staged siblings under `.migration/webui-api/generated/`). No component writes into another component directory.
- Encoding: new/edited files UTF-8; files patched downstream (`eq3/rega.tcl`) keep ISO-8859-1/CRLF.

Gate markers: `[GATED:EG-n]` tasks state a live-CCU/inventory prerequisite. They block ONLY the named task and never unrelated tasks.
