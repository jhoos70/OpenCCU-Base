# Module: www (part 1 of 2) - www/config

## Overview

- Path: `www/config/` (3,185 files on disk: 1,442 `.txt`, 1,090 `.tcl`, 589 `.png`, 38 `.js`, 25 `.cgi`, 1 `.gitignore`; `git ls-files www/config` lists 3,193 entries incl. 8 symlinks)
- Language: Tcl (CGI scripts run via `#!/bin/tclsh`), embedded HTML/JS generated by `puts`, JSON-fragment localization `.txt`, PNG device images.
- Role: legacy ("eq3_old") WebUI backend served under `/config/` on the CCU: (a) the system "Control Panel" popups (`cp_*.cgi`), (b) the device / direct-link parameter configuration engine (`ic_*` CGIs + `easymodes/`), (c) device image/hotspot database, (d) German string table to JS, (e) legacy LCD display CGIs.
- Scope note: only `www/config` is covered here. `www/api`, `www/ise`, `www/pda`, `www/rega`, `www/tools`, `www/webui`, `www/upnp`, `www/tcl` belong to part 2.
- Sampling note: the 2,561 files under `easymodes/` and 589 PNGs were sampled by pattern (directory listing, one representative per pattern, grep of procs); individual per-device profile files were not read one by one. `ic_*.cgi` bodies and `cp_*.cgi` were read via grep plus selective reads, not fully line-by-line.

## Critical finding: two copies of the tree

- The repo contains two trees: `www/config` (this module) and `src/webui/www/config` (source of record). CMake copies `src/webui/www` to the rootfs (`src/webui/CMakeLists.txt:5-6`) and also creates the `cgi.tcl/common.tcl/once.tcl/session.tcl/user.tcl` symlinks (`src/webui/CMakeLists.txt:20-27`).
- `diff -rq www/config src/webui/www/config` reports 49 differences. Examples: `www/config/backup.tcl:11` uses `([+-]\d+)` for the time-zone while `src/webui/www/config/backup.tcl:11` uses `([+-].+)` (commit be2b31ce, 2026-10-02, "accept a time zone offset with colon"); `www/config/ic_common.tcl:1736-1741` defines `put_meta_nocache` which is removed in the src copy (commit 7d8dbddf "rely on HTTP cache headers"); `ic_common.tcl:651` has `AvoidBrowserCache` in `IGNORE_PARAMS`, removed in src.
- Last commit touching `www/config`: 5ad0af6c (2026-06-03, "Updated to version 3.89.2"); last touching src copy: 2026-10-02. Conclusion: `www/config` is a stale deployed snapshot (the build has `DEPLOY_TO_REPO` default ON, `CMakeLists.txt:26`), `src/webui/www/config` is where changes are made.
- Files only in `www/config`: the 8 symlinks (`cgi.tcl`, `common.tcl`, `once.tcl`, `session.tcl`, `user.tcl`, `display/cgi.tcl`, `display/common.tcl`, `display/once.tcl`; targets absolute `/opt/hm/www/tcl/...`, e.g. `www/config/cgi.tcl -> /opt/hm/www/tcl/extern/cgi.tcl`), `st_values.cgi`, `st_values.js` and `devdescr/DEVDB.tcl` (generated). Symlink targets live in part 2 (`www/tcl/extern`, `www/tcl/eq3_old`) and are dangling inside the repo checkout.
- `devdescr/DEVDB.tcl` is a build artifact: `devdescr/.gitignore` contains `*` / `!.gitignore`, yet DEVDB.tcl is tracked. It is generated by `src/webui/www_source/create_devdb_tcl.tcl`, converted with `utf82ansi.py`, then copied to `www/config/devdescr/DEVDB.tcl` (`src/webui/www_source/CMakeLists.txt:9-13`).

## Request pipeline and common conventions

- Every CGI starts with `source once.tcl` + `sourceOnce cgi.tcl/session.tcl/common.tcl` (+ `loadOnce tclrpc.so` / `load tclrega.so`), e.g. `ic_deviceparameters.cgi:2-7`, `cp_maintenance.cgi:2-8`. `tclrpc.so` provides `xmlrpc`, `tclrega.so` provides `rega`/`rega_script` (calls to ReGaHss).
- Entry point shape (cp_*): `cgi_eval { cgi_input; catch {import debug; cgi_debug -on}; set action "put_page"; catch {import action}; if {[session_requestisvalid 8] > 0} then action_$action }` (`cp_security.cgi:1589-1601`, same in `cp_maintenance.cgi:1408`, `cp_network.cgi:727`, `cp_time.cgi:813`, `cp_display.cgi:253`, `cp_software.cgi:548`, `cp_add_device.cgi:976`). Dispatch is by URL parameter `action` to proc `action_<name>`; no whitelist beyond the proc name existing.
- Access levels: `cp_*` require session level 8 (admin). `ic_*` CGIs require level 0 (`ic_deviceparameters.cgi:1383`, `ic_linkpeerlist.cgi:696`, `ic_selchannel.cgi:1250`, `ic_seldevice.cgi:715`, `ic_setprofiles.cgi:765`, `ic_ifacecmd.cgi:814`, `ic_deviceFirmwareOverview.cgi:262`); `ic_md.cgi:60` requires 8 for the write path. Expert mode gate via `session_is_expert` (e.g. `ic_setprofiles.cgi:196,336`, `ic_selchannel.cgi:933`) hides the "Expertenprofil" (profile 0).
- Session id is carried as `sid` parameter, injected into forms (`ic_common.tcl:480` `$sidname`/`$sid`) and into JS URLs (`cp_software.cgi:508-520`).
- HTML generation: either CGI helper DSL (`html {}`, `head {}`, `table_row {}` from `cgi.tcl`) or raw `puts`. Strings are i18n placeholders like `\${dialogSettingsCMTitle}` resolved client-side by the JS translation layer (`translatePage(...)`, `ic_deviceparameters.cgi:62-66`) from the string table; German literals remain in older code.
- State files read/written by CGIs: `/etc/config/netconfig`, `/etc/config/time.conf`, `/etc/config/TZ`, `/etc/config/ntpclient`, `/etc/config/hss_lcd.conf`, `/etc/config/syslog`, `/etc/config/keys`, `/etc/config/ic_settings.dat`, `/etc/config/userprofiles/`, `/etc/config/InterfacesList.xml`, `/etc/config/tweaks`, `/etc/config/server.pem`, `/var/ids` (SerialNumber), `/var/hmip_board_sgtin`, `/etc/eq3services.ports.tcl`.

## Device / link configuration engine (`ic_*`)

Profile file contract (from `SWITCH/KEY.tcl`):
1. `source em_common.tcl`, `EnterFreeValue.tcl`, `etc/options.tcl` (`:3-5`).
2. Declare `PROFILES_MAP(n)` display names as i18n keys (`:7-11`) and `PROFILE_n(...)` arrays of paramset values (e.g. `LONG_JT_ON`, `SHORT_ON_TIME`, `UI_DESCRIPTION`, `UI_TEMPLATE`, `UI_HINT`); profile 0 is the "expert" profile. Value form `{111600 range 0.0 - 111600.0}` marks adjustable values.
3. Define `proc set_htmlParams {iface address pps pps_descr special_input_id peer_type}` which fills `HTML_PARAMS(separate_$prn)` with hidden `<textarea>` blocks containing the per-profile HTML (`:140-...`); calls `get_cur_profile2` to detect the active profile and emits `getLangInfo(sender, receiver)` JS to load texts.
4. End with `constructor` (`em_common.tcl`).
The loader (`ic_setprofiles.cgi:216 recycle_easymodes`, `ic_deviceparameters.cgi:185`) clones profile HTML for user-created sub-profiles (`pnr` of form `N.M`) and injects JS `recycle_arr` values.

## Observations / technical debt (evidence-based)

- Stale duplicate tree (see above); edits must target `src/webui/www/config`.
- Command execution from request input: `cp_software.cgi:493` `exec $script $op` with `script`/`op` imported from the request, protected only by admin session (`:548`); `crypttool ... -k "$key"` receives user keys after regex validation only in `action_change_key` (`cp_security.cgi:158`), other call sites at `:275`, `:539`, `:547` take `key` unvalidated (Tcl `exec` does not use a shell, limiting injection to argument values).
- Dynamic dispatch `action_$action` with raw param (all cp_* CGIs) - any `action_*` proc in scope is callable.
- Hard-coded absolute paths and hosts (`/www/config/...` in `hmip/*.tcl`, `/opt/hm/...` symlinks, `/etc/config/*`, `/var/*`, `/usr/local/*`) and product branching (`getProduct < 3` CCU2 vs CCU3, `isOldCCU`) throughout `cp_*`.
- Very large generated-by-hand HTML-in-Tcl procs (`hmipChannelConfigDialogs.tcl` 8.3 KLOC, `hmip_helper.tcl` 3.2 KLOC) with HTML emitted through string concatenation and embedded inline JS; heavy copy/paste across the 2,500 easymode files (e.g. identical `PROFILE_n` blocks, `SWITCH/KEY.tcl`).
- Latin-1 source encoding mixed with UTF-8 (`cp_security.cgi`), a build step `utf82ansi.py` re-encodes generated files.

## Migration-relevant facts

- Authentication surfaces: (a) ReGa session ids `@XXXXXXXXXX@` (12 chars) validated with ReGa script calls from Tcl; (b) legacy file-based sessions `/var/SESSIONS.dat` and users `/etc/config/USERS.dat`; (c) login is performed by HTTP POST to the local ReGa `/login.htm` from Tcl.
- Authorization: central-only per-method levels in `methods.conf`; the configuration-tool mode (`DOCUMENT_ROOT != /www/`) skips privilege checks (`homematic.cgi:147-148`).
- `api/backup/binfile.cgi`, `api/backup/textfile.cgi`, `api/backup/tarfile.cgi` read caller-selected paths with only a session check.
